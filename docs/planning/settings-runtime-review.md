## 변경 내용

### 740 공통 환경설정

홈과 로비에서 기존 설정 화면 및 저장 시스템을 공유한다. 로비 환경설정을 열고 닫아도 방 연결과 Lobby 상태를 유지한다. 미적용 변경은 확인 절차를 거쳐 버리고, 캐시된 화면 재진입 시 저장값으로 새 초안을 만든다. 설정 화면 동안 채팅과 카메라 입력을 차단하고, 다른 참가자가 게임을 시작하면 설정 화면을 닫는다.

사용자 확인에 따라 피드백 보내기는 기존 미연결 안내를 유지하고 API 전송은 후속 작업이다. 언어는 기존 한국어 목록을 유지한다.

### 743 카메라

1인칭 마우스 감도·X/Y 반전, 3인칭 마우스 및 카메라 감도·X/Y 반전을 실제 카메라에 연결한다. 기본 감도 50은 기존 회전 속도를 유지한다. 0~100을 0~2배로 매핑하며, 3인칭은 마우스와 카메라 배율을 곱한다(두 값 모두 100이면 4배). V 시점 전환은 커서를 캡처한 상태에서만 허용한다.

### 744 인터페이스와 이름 공개

- HUD UI 및 글자 크기: 작게 85%, 중간 100%, 크게 115%. 기본 화면은 기존 크기를 유지하고 반복 적용 시 배율이 누적되지 않도록 처리한다.
- 인게임 UI 끄기: 일반 HUD·상호작용 안내를 숨기며 보이지 않는 채팅이 입력을 가져가지 않게 한다. 아이템 배정·페이즈 전환·하이라이트·결과 안내는 유지한다. 로비 메뉴는 계속 접근 가능하다.
- FPS와 핑: 0.5초마다 갱신한다. FPS는 로컬 프레임 평균, 핑은 Fusion의 로컬 플레이어 RTT(ms)이며 네트워크 처리 시간을 포함한다. 세션 측정 불가 시 `Ping —` 표시.
- 초심자 가이드 켜기: 기존 L키 가이드 숨김보다 우선해 상시 표시한다. 끄기에서는 기존 L키 표시 전환을 유지한다.
- 다른 플레이어 이름: 전체/친구/끄기를 로컬 화면에 반영한다.
- 내 이름 공개: 소유자 입력 권한 RPC로 전체/친구/끄기와 같은 방의 허용 계정 목록을 상태 권한에 전달한다. 공개 설정이 도착하기 전에는 이름을 숨긴다. 0.25초 간격으로 상태를 확인하되 실제 전송은 값이 달라질 때만 한다.
- 친구 판별: 닉네임이 아닌 계정 ID와 기존 친구 목록을 사용한다. 전체 친구 목록을 네트워크에 보내지 않고 같은 방에서 허용할 계정만 전달한다.
- 이름 끄기: 사용자 결정대로 이름 문자열을 완전히 비운다. 이름표, 로비 참가자 목록, 채팅 이름, 숨기기 상태 및 하이라이트 제목에 적용한다. 공개 상태 변경 시 열려 있던 강퇴·위임 확인도 닫아 이전 이름이 남지 않게 한다.
- 채팅 친구 범위: 메시지 목록과 머리 위 말풍선을 필터링한다. 자신의 메시지는 유지하며 친구 목록 변경 시 현재 채팅 목록도 갱신한다.

공개 범위는 정상 클라이언트의 **화면 표시 정책**이다. 기존 복제 닉네임·계정 ID 및 채팅 원문을 암호화하거나 상대 메모리에서 제거하는 기능은 아니다. 채팅 내용에 사용자가 직접 작성한 이름까지 가리지 않는다.

741 그래픽 고급 옵션, 742 오디오·마이크 연결, 일반 행동 키 재지정은 이번 묶음에 포함하지 않는다.

## 검증

- Unity 6000.3.22f1, WebGL 대상 Editor 컴파일.
- 병합 후 관련 EditMode **174/174 통과**: 설정 적용/취소, 카메라, HUD, 초대 알림, 채팅 필터, 계정 ID 기준 친구 판별, 서로 독립된 두 표시 환경에서 비공개 이름 숨김, 친구 변경, 설정 저장 복원 등.
- PlayMode **4/4 통과**: 실제 SettingsView와 PlayerCameraRig, HUD 크기·글자 복원 및 필수 안내 유지, 숨긴 채팅 입력 해제, 실제 NetworkedPlayer 프리팹의 Fusion Single 스폰·공개 설정 RPC·하이라이트 후 상호작용 HUD 복원 검증.
- `git diff --check` 통과.
- 실제 두 클라이언트 사이 Photon 전송과 WebGL 브라우저 플레이는 미검증. 두 표시 환경 테스트와 Fusion Single 테스트는 실제 2인 네트워크 테스트를 대신하지 않는다. WebGL 전체 빌드·배포 미실행.
- 기존 확장 실행의 PlaySettingsPresenterTests 2건은 미지원 `food`/`fruit` 카테고리 보존 기대값으로 실패했다. 해당 테스트·뷰·카탈로그·규칙 모델은 기준 develop과 동일하며 이번 변경에 포함하지 않았다. 별도 기준 브랜치 실행으로 재현한 결과는 아니다.

작업 공간 상위 `.build/settings-merge-editmode.xml`, `.build/settings-merge-playmode.xml`에 병합 후 결과를 보관한다. develop에 추가된 `IHomeApplicationHost.JoinRoom`은 이번 PlayMode 테스트 대역에도 반영했다.

네트워크 프리팹에 복제 상태가 추가되므로 실제 멀티플레이 검증·배포 시 모든 참가자는 같은 새 빌드를 사용해야 한다. 이전 빌드와 혼용하지 않는다. 실제 프리팹 스폰 테스트는 변경된 상태 레이아웃을 확인하는 용도도 겸한다.

## 사용자 확인 순서

1. 홈 설정에서 적용·취소·재진입, 재실행 후 저장값 유지 확인.
2. 로비 Esc → 환경설정 → 적용/뒤로가기: 방 연결·메뉴 복귀, 설정 중 이동·시점 전환·채팅 차단 확인.
3. 1인칭/3인칭 감도·축 반전, 기본값 50의 기존 조작감 확인.
4. HUD 크기·글자 크기·FPS·핑·가이드·인게임 UI 토글 확인. HUD를 꺼도 배정/전환/엔딩을 볼 수 있고 숨겨진 채팅이 Enter 입력을 잡지 않는지 확인.
5. 같은 새 빌드의 두 참가자로 A 이름 공개 끄기 → B 이름표·참가자 목록·채팅·숨기기/하이라이트에서 이름이 없는지 확인. A를 친구로 추가/삭제하며 ‘친구만’ 및 B의 로컬 이름 표시 범위 확인.
6. 채팅 전체/친구 변경 및 친구 삭제 시 목록·말풍선 숨김 확인. 재접속·게임 재시작·설정 화면 중 호스트 시작도 확인.
