# [와이어] 방 만들기 모달창 구현

- 이슈: GAME-451
- 담당: 김채린

새 방의 공개 여부·제목·인원을 정하는 모달.

## 화면 배치

- [x] 화면 중앙에 모달이 있고, 뒤 화면은 가려지거나 딤 처리된다
- [x] Public / Private 선택이 있다
- [x] 방 제목 입력칸이 있다
- [x] 최대 인원 조절이 있다
- [x] 생성 / 취소(닫기)가 있다

## 동작

- [x] Public / Private을 누르면 선택 표시가 바뀐다
- [x] 제목이 비어 있으면 생성이 꺼져 있다
- [x] 제목을 1~20자 넣으면 생성이 켜진다
- [x] 인원 조절 시 숫자가 바로 바뀐다
- [x] 생성을 누르면 모달이 닫히고 로비로 넘어간다
- [x] 취소/닫기를 누르면 이전 화면이 다시 보인다

## 유스케이스

- [x] 공개/비공개와 제목·인원을 정한 뒤 방을 만든다
- [x] 제목 없이 방을 만들 수 없다
- [x] 만들기를 취소하고 이전 화면으로 돌아간다
