# [와이어] Home 메인 페이지 구현

- 이슈: GAME-355
- 담당: 양혜림

허브 화면. 여기서만 방 만들기·게임 찾기·설정류·종료로 들어간다.

## 화면 배치

- [x] 화면 중앙에 내 캐릭터 미리보기가 있다
- [x] 우측 하단에 프로필/닉네임이 있다
- [x] `방 만들기` / `게임 찾기` / `옷장 바로가기` / `환경설정` 버튼이 한 묶음으로 보인다
- [x] `게임 종료` / `서버 설정` / `친구 목록` 버튼이 보인다
- [x] 하위 화면은 이 화면 위에 페이지 전환 또는 모달로 겹친다

## 동작

- [x] 각 버튼을 누르면 해당 화면/모달이 열린다
- [x] 하위 화면을 닫으면 버튼·캐릭터·프로필이 그대로인 Home이 다시 보인다
- [x] `게임 종료`는 확인 뒤에만 진행한다

## 유스케이스

- [x] 방을 만들거나 찾아 로비로 들어간다
- [x] 설정·옷장·친구·프로필·서버를 열었다가 Home으로 돌아온다
- [x] 게임을 종료한다
