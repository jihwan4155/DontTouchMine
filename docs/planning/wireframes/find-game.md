# [와이어] 게임 찾기 페이지 구현

- 이슈: GAME-453
- 담당: 양혜림

공개 방 목록과 코드 입장이 있는 화면.

## 화면 배치

- [x] 상단에 방 제목 검색창과 새로고침이 있다
- [x] 본문에 방 리스트가 있다
- [x] 각 행에 방 이름 / 맵 / 인원 / 방장 닉네임 / 게임중 여부가 있다
- [x] 방 코드 입력칸(6자리)과 입장 버튼이 있다
- [x] 뒤로가기가 보인다

## 동작

- [x] 제목을 입력하면 목록이 걸러진다
- [x] 목록은 최신순, 같은 시간이면 방 이름순이다
- [x] 게임중인 방은 눌러도 들어가지 않고, 비활성 또는 안내로 구분된다
- [x] 방 코드는 소문자를 대문자로 바꾼다
- [x] 잘못된 코드·없는 방이면 입력칸 근처에 안내가 뜬다
- [x] 입장 가능한 방을 누르면 로비로 넘어간다
- [x] 뒤로가기를 누르면 Home으로 돌아간다

## 유스케이스

- [x] 목록에서 방을 골라 들어간다
- [x] 검색으로 방을 좁혀 들어간다
- [x] 방 코드로 바로 들어간다
- [x] 게임중인 방에는 들어가지 못한다
