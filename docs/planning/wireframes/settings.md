# [와이어] 환경설정 페이지 구현

- 이슈: GAME-406
- 담당: 김채린

탭으로 나뉜 설정 화면. 바꾼 뒤에만 적용·초기화를 쓸 수 있다.

## 화면 배치

- [x] 상단 또는 좌측에 탭 6개가 있다 (일반 / 그래픽 / 인터페이스 / 사운드 / 컨트롤 / 알림)
- [x] 탭 아래(또는 옆)에 해당 탭 옵션 목록이 있다
- [x] 그래픽 탭: 디스플레이 모드, 해상도, FPS 제한, 안티앨리어싱, HBAO, 텍스처/그림자 품질, 피사계 심도, 볼륨
- [x] 인터페이스 탭: UI/글자 크기, 게임 내 UI, FPS·핑 표시, 닉네임 공개 범위, 채팅 범위
- [x] 사운드 탭: 마스터/배경음/환경음/효과음, 마이크 장치·입력모드·볼륨·테스트
- [x] 컨트롤 탭: 1인칭/3인칭 마우스·카메라 감도, X/Y축 반전
- [x] 알림 탭: 게임중 / 친구요청 / 게임초대 on-off
- [x] 하단(또는 고정 영역)에 초기화 / 적용 / 이전이 있다

## 동작

- [x] 탭을 누르면 그 탭 내용만 보인다
- [x] 값을 바꾸기 전에는 초기화·적용이 꺼져 있다
- [x] 값을 바꾸면 초기화·적용이 켜진다
- [x] 적용하지 않고 나가려 하면 저장 확인 모달이 뜬다
- [x] 이전을 누르면 들어온 화면으로 돌아간다

## 유스케이스

- [x] 탭을 옮겨 가며 옵션을 보고 적용한다
- [x] 잘못 바꾼 값을 초기화한다
- [x] 저장하지 않고 나가려다 확인 모달에서 남거나 버린다
