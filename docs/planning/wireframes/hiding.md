# [와이어] 물건 숨기기 씬 화면 구현

- 이슈: GAME-361
- 담당: 양혜림

배정 물건을 맵에 숨기는 단계 HUD.

## 화면 배치

- [x] 배정 물건 안내 문구가 화면 전면(중앙 또는 상단)에 있다
- [x] 숨기는 사람에게 남은 시간이 보인다
- [x] 숨기는 사람에게 완료 버튼이 있다
- [x] 대기자에게 순서 안내(`N/6명`)가 있다
- [x] 캐릭터 위에 채팅 텍스트가 붙는다
- [x] 이 단계임이 한눈에 구분된다

## 동작

- [x] 배정 안내 문구는 잠시 보이다가 사라진다
- [x] 숨기는 사람의 남은 시간이 줄어든다
- [x] 완료를 누르면 숨기기가 끝나고 대기/다음 흐름으로 바뀐다
- [x] 시간이 끝나면 완료를 누르지 않아도 배치된 것처럼 다음으로 넘어간다
- [x] 대기자는 이동은 되지만 숨기기 완료 UI가 없다

## 유스케이스

- [x] 숨기는 사람이 물건을 놓고 완료한다
- [x] 시간 안에 못 끝내면 자동으로 다음으로 넘어간다
- [x] 대기자가 자기 차례와 남은 인원을 본다
- [x] 채팅이 캐릭터 위에 보인다
