# [와이어] 게임중 씬 화면 구현

- 이슈: GAME-367
- 담당: 김채린

탐색·파괴가 진행되는 본 매치 HUD.

## 화면 배치

- [x] 전체 남은 시간이 고정 위치(상단 등)에 있다
- [X] 스테미나 바와 체력 바가 있다
- [x] 카테고리 + 배정 물건(남은 / 파괴된)이 한 덩어리로 보인다
- [x] 키 세팅 가이드가 있다
- [x] 캐릭터 위에 채팅 텍스트가 붙는다
- [x] HUD가 화면 가장자리·하단에 모여 시야 중앙을 가리지 않는다

## 동작

- [x] 남은 시간이 줄어든다
- [x] 스테미나/체력이 바 길이로 변한다
- [x] 물건이 남거나 파괴되면 목록 표시가 바뀐다
- [x] 채팅을 보내면 캐릭터 위에 문구가 떴다 사라진다

## 유스케이스

- [x] 남은 시간·체력·스테미나를 보며 움직인다
- [x] 어떤 물건이 남았는지/파괴됐는지 확인한다
- [x] 키 가이드를 보고 조작한다
- [x] 채팅으로 의사소통한다
