# [와이어] 하이라이트 씬 화면 구현

- 이슈: GAME-455
- 담당: 김채린

엔딩 다음 자동 재생 화면. 클립 3개 × 10초.

## 화면 배치

- [x] 화면 대부분을 하이라이트 영상이 차지한다
- [x] 현재 클립 / 전체(3개) 진행이 구분되어 보인다
- [x] 개별 skip과 전체 skip이 가장자리에 있다
- [x] 되돌아가기 버튼은 없다

## 동작

- [x] 엔딩이 끝나면 첫 클립이 자동으로 재생된다
- [x] 클립이 끝나면 다음 클립이 이어진다 (3개)
- [x] 개별 skip을 누르면 다음 클립으로만 간다
- [x] 전체 skip을 누르면 하이라이트가 끝나고 로비 복귀로 간다
- [x] skip한 클립으로 되돌아갈 수 없다
- [x] 3개가 끝나면 로비 복귀로 이어진다

## 유스케이스

- [x] 하이라이트 3개를 순서대로 본다
- [x] 한 클립만 건너뛴다
- [x] 전체를 건너뛰고 로비로 돌아간다
