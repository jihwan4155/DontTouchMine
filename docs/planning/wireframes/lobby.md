# [와이어] 로비 페이지 구현

- 이슈: GAME-383
- 담당: 김채린

매치 시작 전 대기 공간. 참여자·채팅·방 설정이 한 화면에 있다.

## 화면 배치

- [x] 참여자 목록: 닉네임, 방장 왕관, 마이크 상태, (방장만) 강퇴
- [x] 채팅 영역과 입력칸이 있다
- [x] 게임 초대 버튼이 있다 (가득 차면 숨김)
- [x] 환경설정 / 캐릭터 설정 진입이 있다
- [x] 게임 나가기가 있다
- [x] 방장에게만 방 설정이 보인다: 제목, 방 코드 복사, 인원(2~6)
- [x] 방장에게만 규칙 설정이 보인다: 파괴 횟수(무한), 숨는 시간, 찾는 시간, 달리기 배율, 기절 HP
- [x] 맵 / 물건 카테고리(랜덤·과일·기타)가 모두에게 보인다
- [x] 게임 시작 버튼이 있다
- [x] 시작 후 카운트다운이 화면 중앙에 뜬다

## 동작

- [x] Enter로 채팅이 켜지고, 전송 후 다시 꺼진다
- [x] 방장이 강퇴하면 해당 칸이 목록에서 사라진다
- [x] 인원이 가득 차면 초대 버튼이 숨겨진다
- [x] 일반 유저가 나가기를 누르면 바로 로비를 떠난다
- [x] 방장이 나가기를 누르면 방 폭파 경고 모달이 뜬다
- [x] 방장이 설정을 바꾸면 화면에 바로 반영된다
- [x] 시작을 누르면 10초 카운트다운이 보이고, 끝나면 숨기기 씬으로 넘어간다

## 유스케이스

- [x] 참여자를 보고 채팅·초대를 한다
- [x] 방장이 규칙·맵을 정한 뒤 게임을 시작한다
- [x] 방장이 아닌 사람은 설정·시작을 만지지 못한다
- [x] 환경설정·캐릭터를 열었다가 로비로 돌아온다
- [x] 방을 나가거나(방장은 폭파 확인 후) Home/게임 찾기로 돌아간다
