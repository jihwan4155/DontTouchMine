# [와이어] 프로필 설정 모달창 구현

- 이슈: GAME-450
- 담당: 양혜림

닉네임과 검색 허용을 바꾸는 모달.

## 화면 배치

- [x] 화면 우측 하단에 패널이 있고, 뒤 Home은 딤 처리되지 않는다
- [x] 현재 닉네임이 보인다
- [x] 닉네임 입력칸과 중복 체크 버튼이 있다
- [x] `닉네임 검색 허용` 토글이 있다
- [x] 적용 / 닫기가 있다

## 동작

- [x] 중복 체크를 통과하기 전에는 적용이 꺼져 있다
- [x] 중복이면 적용이 꺼져 있다
- [x] 통과하면 적용이 켜진다
- [x] 닫으면 패널이 닫힌다

## 유스케이스

- [x] 닉네임을 바꾸고 중복 확인 후 적용한다
- [x] 중복 닉네임은 적용하지 못한다
- [x] 닉네임 검색 허용을 켜거나 끈다
