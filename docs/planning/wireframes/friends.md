# [와이어] 친구 목록(추가) 모달창 구현

- 이슈: GAME-449
- 담당: 양혜림

Home 위에 뜨는 친구 모달. 목록 보기와 친구 추가가 탭으로 갈린다.

## 화면 배치

- [x] 화면 우측 하단에 패널이 있고, 뒤 Home은 딤 처리되지 않는다
- [x] 상단에 `친구 목록` / `친구 추가` 탭이 있다
- [x] 목록 탭: 새로고침, 닉네임 검색창, 친구 행(닉네임·상태)
- [x] 추가 탭: 받은 요청 목록(수락/거절), 닉네임 검색창, 요청 보내기
- [x] 닫기 버튼이 없다

## 동작

- [x] 탭을 바꾸면 해당 목록만 보인다
- [x] 목록 탭에서 검색하면 보이는 친구가 걸러진다
- [x] 목록은 온라인 → 오프라인(스팀 온라인) → 오프라인(스팀 오프라인) 순이다
- [x] 새로고침을 누르면 목록이 다시 그려진다
- [x] 추가 탭에서 닉네임을 검색하고 요청을 보낸다
- [x] 받은 요청에서 수락/거절을 누르면 해당 행이 갱신된다
- [x] Home은 딤 없이 그대로 보이고, 패널은 우측 하단에 떠 있다

## 유스케이스

- [x] 친구 상태를 보고 검색한다
- [x] 받은 요청을 수락하거나 거절한다
- [x] 닉네임으로 친구를 찾아 요청을 보낸다
