# [와이어] 서버 설정 모달창 구현

- 이슈: GAME-452
- 담당: 김채린

리전을 고르는 모달.

## 화면 배치

- [x] 화면 우측 상단에 패널이 있고, 뒤 Home은 딤 처리되지 않는다
- [x] 아시아 / 북미 / 오세아니아 / 유럽이 선택 목록으로 보인다
- [x] 지금 고른 리전이 강조된다
- [x] 적용(또는 선택 확정) / 닫기가 있다

## 동작

- [x] 리전을 누르면 선택 표시가 그쪽으로 옮겨간다
- [x] 확정하면 모달이 닫히거나 선택 상태가 유지된 채 닫힌다
- [x] 다시 열면 마지막에 고른 리전이 강조되어 있다
- [x] 닫으면 Home이 다시 보인다

## 유스케이스

- [x] 리전을 고르고 확정한다
- [x] 나중에 다시 열어 현재 리전을 확인하거나 바꾼다
