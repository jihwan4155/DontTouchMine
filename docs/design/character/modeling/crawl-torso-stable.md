# Crawl torso shape preservation

The shared First character body now holds the central capsule on the Spine bone.
Previously its arm and leg weights, combined with asymmetric crawl corrective
shapes, pulled the flank inward as each thigh lifted. The arm and thigh joints
retain a smooth weight transition into their articulated limbs.

- Updated the common `FirstPlayerCapsule_Idle.fbx` mesh and 29 crawl/prone FBXs
  under `Assets/Scenes/CharacterTest/First`.
- Changed 3,948 body vertices' skin weights; 2,096 central vertices form the
  fully held region in Blender. This is a shared mesh correction and therefore
  also affects how the body deforms when other animations use the Idle model.
- Neutralized the geometry of `Crawl_Waist_Round`, `Crawl_Follow_L`, and
  `Crawl_Follow_R`, retaining their names and animation bindings.
- Preserved skeletal animations, animation durations, other shape keys,
  materials, and Unity asset GUIDs.

## Verification

All 30 exported FBXs were reimported in Blender and checked for finite mesh
coordinates, unchanged bone poses (roundtrip tolerance 0.0001), unchanged
durations, and loop closure where the original clip was closed.

An isolated Unity 6000.3.22f1 project sampled the updated Idle model with all 13
crawl clips, including carry directions and the crawling throw: 469 frames,
zero validation errors. The held region's maximum movement relative to Spine
was below 0.000000043 Unity coordinate units while the feet continued moving.
This checks Unity's imported FBX skinning; it does not claim a Play Mode run in
the main project.

## Reproduction

Run `Tools/stabilize_crawl_torso.py` using Blender with `--python-exit-code 1`.
The default stages and verifies the forward crawl only. Append `-- --install`
to stage, verify, back up, and install all 30 affected FBXs. It imports the
mask/export helpers from `Tools/hold_crawl_torso.py` without running that script.
Outputs and first-install backups go to `Temp/crawl-torso-stable`.

Run `Tools/validate_crawl_torso.py` with Python to prepare an isolated QA project,
then launch Unity with that project and
`-executeMethod CrawlTorsoUnityValidation.Run -batchmode -nographics`.
The result is `Temp/crawl-torso-stable/unity-qa/unity-report.json`.

The before/after preview is generated by `Tools/render_stable_crawl.py` in
Blender and packaged with `Tools/package_stable_crawl_preview.py` using Pillow.
