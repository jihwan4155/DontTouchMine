# 프로젝트 문서

기획과 디자인 문서를 관리합니다. 문서도 코드처럼 feature 브랜치에서 수정하고 MR로 병합합니다.

## 구조

```text
docs/
├─ planning/   기획 — 게임 규칙, 시스템 상세, 밸런스 수치
└─ design/     디자인 — UI 시안, 컨셉 이미지, 스타일 가이드
```

## 작성 규칙

- 문서는 Markdown(`.md`)으로 작성합니다. PDF와 달리 변경 내역이 MR에서 그대로 보입니다.
- 이미지는 주제 폴더 안에 함께 두고 상대경로로 링크합니다. 예: `![](hud-layout-v2.png)`
- 이미지 파일명은 영문 소문자와 하이픈을 사용합니다. 예: `hud-layout-v2.png`
- 이미지(png/jpg)는 Git LFS가 자동으로 처리하므로 용량은 신경 쓰지 않아도 됩니다.
